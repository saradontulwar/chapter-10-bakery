A boutique, Pinterest-inspired pastel website for **Chapter Ten – Bakery Kitchen**, a real bakery and dessert kitchen located in **Pimpri Colony, Pune, Maharashtra, India**.

## 🍰 Features & Website Structure

1. **Announcement Strip:** Top banner celebrating everyday sweet moments with location badge (`Pimpri, Pune`).
2. **Editorial Wordmark & Navigation:** Responsive navigation with sticky frosted glass effect and mobile drawer menu.
3. **Editorial Hero Section:** Asymmetric layout featuring the headline *"Your next little sweet escape"*, high-resolution bakery photography, floating sticker badges (*"Baked Fresh Daily"*, *"Pimpri Colony, Pune"*), and 5.0 rating pill.
4. **Scalloped Section Dividers:** Custom organic scalloped dividers harmonizing blush pink, powder blue, vanilla cream, and biscuit beige sections.
5. **Featured Treats ("A Few of Our Favourite Things"):** Interactive showcase of signature bakes including Strawberry Cream Slice, Bespoke Celebration Cake, French Tarts & Éclairs, and Sea Salt Chocolate Chunk Cookies.
6. **Café Moment Section ("Coffee Dates & Little Delights"):** Dedicated powder-blue section celebrating the atmosphere of relaxed coffee catch-ups and afternoon treats.
7. **Interactive Menu Preview ("The Sweet Chapter Menu"):** Tabbed category browsing (Cakes, Pastries & Tarts, Cookies & Bakes, Café Sips) with transparent culinary descriptions and seasonal rotation notices.
8. **Brand Story ("Every Place Has a Story."):** Warm, honest editorial story reflecting Chapter Ten's dedication to real butter, Belgian chocolate, and celebration memories.
9. **Curated Photo Gallery ("Little Things Worth Looking At"):** Pinterest-style visual grid with an interactive lightbox photo viewer modal.
10. **Visit Us & Finding the Bakery:** Full verified Sukhwani Castle address, Google Maps direct navigation button, kitchen hours notice, and Instagram connection.
11. **Custom Celebration Cake Inquiry Assistant:** A functional modal allowing visitors to select their event occasion, required date, guest count/servings, and flavor notes, with 1-click clipboard copying and direct Instagram DM reach-out.
12. **SEO & Structured Data:** Semantic HTML5, Google Fonts (`Fraunces`, `Nunito`, `DM Sans`), OpenGraph metadata, and Schema.org `LocalBusiness` JSON-LD structured data.

## 🛠️ Technology Stack

* **Framework:** React 19 + Vite
* **Styling:** Custom Vanilla CSS Design System with CSS variables and responsive clamp typography
* **Icons:** Lucide React + Custom SVG Brand Icons
* **Typography:** Fraunces (Headings) & Nunito / DM Sans (Body & Nav)

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build
```
The dev server runs at `http://localhost:5173/`.
